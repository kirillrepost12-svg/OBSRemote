# OBS Remote

Мобильный пульт для управления потоковой трансляцией в OBS Studio.
Android-приложение на Kotlin (Jetpack Compose), которое по Wi-Fi подключается к OBS и позволяет управлять эфиром с телефона.

## Возможности

- Подключение по IP, порту и паролю (данные запоминаются)
- Старт и остановка трансляции
- Старт и остановка записи
- Переключение сцен одним нажатием, текущая сцена подсвечивается
- Включение и выключение звука у источников (микрофон, звук рабочего стола и т.д.)
- Состояние синхронизируется с OBS в реальном времени: если сцену сменили на компьютере, на телефоне она тоже изменится
- Экран телефона не гаснет, пока приложение открыто

## Стек

- Kotlin, Android Studio
- Jetpack Compose + Material 3
- OkHttp WebSocket
- Корутины и Flow
- Протокол [obs-websocket v5](https://github.com/obsproject/obs-websocket/blob/master/docs/generated/protocol.md) (встроен в OBS 28 и новее)

## Как пользоваться

1. В OBS откройте **Инструменты → Настройки WebSocket-сервера**.
2. Включите **Включить WebSocket-сервер**, порт по умолчанию 4455.
3. Включите аутентификацию и нажмите **Показать информацию о подключении**, чтобы узнать пароль (или отключите аутентификацию).
4. Телефон и компьютер должны быть в одной Wi-Fi сети. Узнайте IP компьютера (в Windows: `ipconfig`, строка «IPv4-адрес»).
5. Если не подключается, разрешите OBS во входящих подключениях брандмауэра Windows для частной сети.
6. Откройте приложение, введите IP, порт, пароль и нажмите **Подключиться**.

## Сборка

1. Откройте папку проекта в Android Studio (**File → Open**).
2. Дождитесь окончания Gradle Sync.
3. **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

Готовый APK лежит в этом репозитории в папке `release/`.

## Структура проекта

```
app/src/main/java/com/example/obsremote/
  ObsClient.kt      WebSocket-клиент протокола obs-websocket v5 (рукопожатие, пароль, запросы, события)
  ObsViewModel.kt   состояние приложения и команды для OBS
  Screens.kt        экран подключения и экран управления (Compose)
  MainActivity.kt   точка входа
release/            APK-файл приложения
```

## Как работает подключение

1. Приложение открывает WebSocket `ws://IP:порт`.
2. OBS присылает `Hello` (при включённом пароле вместе с `salt` и `challenge`).
3. Приложение отвечает `Identify` с ответом на challenge: `base64(sha256(base64(sha256(пароль + salt)) + challenge))`.
4. После `Identified` приложение отправляет запросы (`GetSceneList`, `SetCurrentProgramScene`, `ToggleStream`, `ToggleRecord`, `ToggleInputMute`) и слушает события OBS.
